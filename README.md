# Quote Lab

> A Flutter fundamentals project that is actively in development.

Quote Lab is a small random-quote generator built while I learn the foundations of Flutter and mobile app development. It is an evolving practice project, not a finished production application.

## Status

🚧 **In development** — I am still learning Flutter fundamentals and will continue improving the app as I explore layouts, state, theming, and interaction design.

## Current features

- Random motivational quotes
- A polished Material 3 dark interface
- Responsive, focused single-screen layout
- Animated quote transitions

## What I am learning

- Flutter widgets and layout composition
- Stateful interaction with setState
- Material 3 themes and color schemes
- Responsive UI design
- Organizing a Flutter project

## Run locally

1. Install the [Flutter SDK](https://docs.flutter.dev/get-started/install).
2. Clone this repository.
3. Fetch dependencies:

    flutter pub get

4. Run the app on an emulator, simulator, browser, or connected device:

    flutter run
